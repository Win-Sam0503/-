# 餐飲科訂貨系統（網站）

給餐飲科老師下單用的網站，資料全部存在 Google 試算表「訂貨表2.0」。

## 功能

**老師**
- 用「帳號設定」裡的帳號密碼登入（帳號需勾選「啟用」），每次登入都記到「登入資訊」。連續輸錯 5 次會暫停登入 10 分鐘。
- 填上課資訊：上課日期、科別（中餐、西餐、烘焙、飲調、果雕、刀功）、上課時間（上午／下午＋幾點＋幾分，每 5 分鐘）、教室、班級、實作項目，也可以代其他老師訂。
- **鎖單**：每週一中午 12:00 截止「下週」的訂單（週四送單給廠商）。截止前最早可以訂下週一起的課；截止後最早只能訂下下週一起的課。最晚可以訂 30 天內的課，週末不能選。選好日期後會顯示星期和送貨組別（一二／三四五）。
- 從「食材總表」搜尋食材，別名也搜得到，可以依廠商篩選；預設只顯示本科別與「通用」的食材。
- 同一樣食材可以重複加入，每次都是獨立的一列，各自有數量、單位、備註（例如雞蛋 10 顆打發用、雞蛋 5 顆裝飾用）。
- **單位用選單選**：叫貨單位（斤、兩、公斤、g、顆、包…）和配方單位（T、t、杯、ml），不能自由輸入，避免同一個單位有好幾種寫法。
- **有貨（現有庫存）**：勾選的品項會印在請料單上，但不會列入廠商叫貨（例如中餐教室有貨的蒜頭、白米）。
- **段落**：配方可以分段（例如麵包體、抹醬、蛋糕體），烘焙請料單會在段落之間印出段落名稱。
- **組數**：選填，會印在請料單的「共 ＿ 組」。
- **我的範本**：把常用的配方存成範本（每位老師各自的）。範本存的是一組的量，下次帶入時填組數，數量自動乘好。同名的範本會覆蓋。
- 搜尋也可以用舊編號（例如 A07），請料單的教師料單會印出舊編號。
- **使用器具**：自由填寫器具名稱、數量、備註（例如烤盤、蛋糕模），不需要先建清單。每個器具在訂單總表是獨立一列，「食材ID」和「廠商」都寫「器具」。
- **列印請料單**：在「我的訂單」或送出成功的畫面按「列印」，一張訂單印一張 A4，可以選三種格式：
  - 實習專用請料單（材料＋特殊器具）：烘焙預設
  - 實習專用請料單（依廠商分類，標題含實習項目）：中餐預設
  - 教師料單（新版：A｜蛋類＋海鮮｜F／肉類｜乾貨｜上課須用器具）：其他科別預設

  週次、組數、單價、總價、歸還、備註、倉庫負責老師等欄位會留空手寫。
- 填數量、單位、備註後送出，每項食材寫成「訂單總表」的一列，狀態為「待處理」。
- 找不到的食材可以直接提交，跟訂單一起送出（食材 ID 會是「待審核」），同時記到「待審核食材」。
- 還沒送出的清單會自動保存在瀏覽器裡，重新整理或下次登入都還在。
- 「我的訂單」可以看自己送出、或別人代訂的訂單。還沒過訂貨截止、狀態為「待處理」的訂單可以自行取消；**已過截止的訂單不能取消或修改**，要更動請找管理者。「再訂一次」會把舊訂單的食材帶回訂購清單。

**管理者**（帳號「管理者」，可在 `Code.gs` 的 `ADMIN_ACCOUNTS` 增加）
- 不受鎖單限制，可以訂今天起 30 天內的課（臨時加單、補訂）。
- **審核**：訂單狀態多了「已審核」；在訂單彙整按「修改明細」可以直接改數量、單位、備註、有貨，或刪除個別品項。修改或審核時會記錄審核人（只在網站上顯示，不印出來）。老師的訂單一旦審核，就不能自行取消。
- 訂單彙整會把重量單位換算成同一種：菜商、肉商換成「斤」，其他廠商換成「公斤」（1 斤＝600 g、1 兩＝37.5 g）。顆、包、T、t 這類無法換算的照原單位分開加總。勾選「有貨」的品項不列入。
- 試算表如果還缺少新功能需要的欄位或分頁，管理者登入時會看到提醒。
- 訂單彙整的每張訂單也可以列印；使用器具另外列成一個區塊，不會算進廠商叫貨。
- **訂單彙整**：選上課日期區間，依「廠商 → 日期／送貨組別 → 食材」加總數量並列出各班明細。「複製叫貨文字」可以直接貼到 LINE 給廠商。
- 每張訂單都可以改狀態：待處理、已叫貨、已到貨、已取消。
- **審核食材**：老師提交的新食材可以：
  - 核准：加入食材總表，給新的 I 編號；
  - 對應既有食材：其實食材總表已經有；
  - 退回。

  核准或對應後，原訂單裡那項食材的 ID、名稱、廠商會一起更新。

## 新功能需要的試算表設定（請手動新增）

在「訂貨表2.0」加上以下欄位和分頁，**標題文字要完全一樣**。還沒加的話網站照常運作，只是對應的資料不會存起來。

1. **訂單總表**：在最後面加四欄：`組數`、`不叫貨`、`段落`、`審核人`
2. **食材總表**：在最後面加一欄：`舊編號`（填 A01、A07 這類編號，可以留空）
3. **新增分頁「範本」**：第一列依序填
   `老師`｜`範本名稱`｜`科別`｜`實作項目`｜`類型`｜`食材ID`｜`名稱`｜`廠商`｜`一組數量`｜`單位`｜`備註`｜`段落`｜`不叫貨`｜`建立時間`

## 檔案

| 檔案 | 用途 |
|---|---|
| `Code.gs` | 後端程式：登入、讀食材、寫訂單、管理功能 |
| `Index.html` | 網站頁面，手機、電腦都能用 |
| `appsscript.json` | 專案設定：台北時區、網站權限 |

## 部署步驟

建議**另外建一個新的 Apps Script 專案**，不要覆蓋試算表裡現有的程式，這樣舊網站可以保留到新網站確認沒問題為止。

1. 到 <https://script.google.com>，點「新專案」，專案名稱取「餐飲科訂貨系統」。
2. 把 `程式碼.gs` 的內容全部刪掉，貼上 `Code.gs`。試算表 ID 已經填好了，不用改。
3. 點「檔案」旁的 **＋ → HTML**，檔名輸入 `Index`，貼上 `Index.html` 的內容。
4. 左側齒輪 **專案設定**：時區選 `(GMT+08:00) 台北`。
5. 右上角 **部署 → 新增部署作業**：
   - 類型：網頁應用程式
   - 執行身分：**我**
   - 誰可以存取：**所有人**
6. 按「部署」並授權。如果出現「Google 尚未驗證這個應用程式」，點「進階 → 前往（不安全）→ 允許」。這是你自己的程式，所以會出現這個提示。
7. 複製網頁應用程式網址，傳給老師。

> 之後修改程式：**部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，網址不會變。

## 可以調整的設定（`Code.gs` 最上面）

| 設定 | 預設 | 說明 |
|---|---|---|
| `ADMIN_ACCOUNTS` | `['管理者']` | 哪些帳號有管理功能 |
| `DEPARTMENTS` | 中餐、西餐、烘焙、飲調、果雕、刀功 | 科別選單；食材總表裡出現的其他科別也會自動加入 |
| `LOCK_WEEKDAY` | 1 | 每週星期幾截止下週訂單（1 = 星期一 … 5 = 星期五） |
| `LOCK_HOUR`、`LOCK_MINUTE` | 12、0 | 截止時間 |
| `ITEMS_CACHE_MINUTES` | 10 | 食材清單暫存幾分鐘（讓登入變快） |
| `MAX_DAYS_AHEAD` | 30 | 上課日期最晚幾天後 |
| `SESSION_HOURS` | 6 | 登入有效時數 |

## 試算表注意事項

- 程式依**標題文字**找欄位，欄位順序可以調整，但標題文字和分頁名稱不要改。唯一例外：訂單總表的「使用日期」也可以改名為「上課日期」，兩種程式都認得。
- **送貨組別**依「廠商設定」的星期代碼決定。沒有列在廠商設定的廠商：週一、二為「一二」，週三、四、五為「三四五」。
- **直接在試算表改食材總表**（新增、停用、改名）後，網站最多 10 分鐘後才會看到。在網站上「核准」新食材則會立即更新。
- **食材總表的「單位」**有填的話，老師加入食材時會自動帶入；沒填的話老師要自己輸入。
- **適用組別**填「全部」代表每天都能訂；填「一二」或「三四五」則只在那些天出現。
- **安全性**：帳號設定的密碼是明碼，請替每位老師設定不同的密碼，並只把試算表分享給管理者。老師不需要試算表權限，也看不到試算表。
