# 老師訂貨網站

給老師下單用的網站，後端是 Google 試算表「訂貨與庫存管理系統」。

- 網站讀取 **商品主檔** 中「網站上架」打勾的商品，顯示品名、售價和庫存狀態（有貨／庫存少／需調貨）。
- 老師送出的訂單寫入 **客戶訂單**，狀態為「待處理」。一張訂單的每個品項各占一列，訂單編號格式為 `SO-年月日-流水號`。
- 第一次下單的老師會自動加入 **客戶** 分頁（代號 T001、T002…），以電話辨識同一位老師。
- 老師可以在「查詢訂單」輸入姓名和電話，查看處理進度與出貨日期。
- 庫存、需補貨清單和總覽會照試算表原本的公式自動更新。

## 檔案

| 檔案 | 用途 |
|---|---|
| `Code.gs` | 後端：讀商品、寫訂單、查訂單 |
| `Index.html` | 網站頁面（手機、電腦都能用） |
| `appsscript.json` | 專案設定（台北時區、網站權限） |

## 部署步驟（約 5 分鐘）

1. 打開試算表「訂貨與庫存管理系統」，點選選單 **擴充功能 → Apps Script**。
2. 把預設的 `程式碼.gs`（或 `Code.gs`）內容全部刪掉，貼上本資料夾 `Code.gs` 的內容。
3. 點左側「檔案」旁的 **＋ → HTML**，檔名輸入 `Index`（不用打 .html），貼上 `Index.html` 的內容。
4. 點左側齒輪 **專案設定**，把時區改成 `(GMT+08:00) 台北`。
5. 點右上角 **部署 → 新增部署作業**：
   - 類型選「網頁應用程式」
   - 執行身分：**我**
   - 誰可以存取：**所有人**
6. 按「部署」，第一次會要求授權（選你的 Google 帳號 → 進階 → 前往專案 → 允許）。
7. 複製「網頁應用程式網址」，把這個連結傳給老師即可。

> 之後修改程式，要到 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，網址不會變。

## 日常管理

- **上架／下架商品**：在商品主檔勾選或取消「網站上架」欄。
- **改價格**：直接改商品主檔的「售價」，網站重新整理後就是新價格。
- **處理訂單**：在客戶訂單把狀態改成「已出貨」並填交貨日期，老師查詢時會看到。
- **希望到貨日、電話**：在客戶訂單的 M、N 欄；學校、地址和老師備註寫在「備註」欄。

## 注意事項

- 試算表的分頁名稱和欄位順序不要更動，網站是依照這些位置讀寫的。
- 客戶訂單第 2 列 E、F、H、I 欄的公式要保留，網站只寫入其他欄位，品名、單價、金額靠這些公式帶出。
- 「查詢訂單」只要知道姓名和電話就能查到該老師的訂單，不需要密碼。如果需要更嚴格的登入，可以改成要求老師用 Google 帳號登入。
- 網站由你的 Google 帳號執行，老師不需要試算表的權限，也看不到試算表本身。
