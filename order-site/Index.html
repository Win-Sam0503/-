訂單編號

我的課

依學校課表和你自己新增的課列出接下來的課。沒訂貨的課會在每週五下午用 LINE 私訊提醒你；不用訂貨的課按「不用訂貨」就不會再被提醒。
選一位老師，可以幫他標記「不用訂貨」、修改或永久取消學校課表上的課、代訂。
每個國技班一個分頁（例如「國技10班(三)」），輪到的老師那週會出現在他的我的課並提醒。

我的課表

我自己新增的課 夜間部、代課、補課等學校課表沒有的課

我的訂單

包含你送出的訂單，以及別人代你訂的訂單（最近 60 天）。還沒過訂貨截止、狀態為「待處理」的訂單可以自行取消；已截止的訂單無法修改，需要更動請聯絡管理者。

列印請料單

一張訂單印一張 A4。如果按「列印」沒有反應，請按鍵盤 Ctrl + P（Mac：⌘ + P）。

訂單彙整

點一下直接查詢；試算表保留最近約 13 個月，更早的在雲端硬碟「三信家商餐飲科歷史訂單」資料夾。

總課表

試算表「課表」分頁的每週固定課。點一堂課可以改老師、課程、班級、教室、節次，或永久取消／恢復；點空白格子的「＋」可以新增一堂課（新教室請按上面的「新增一堂課」）；改完老師的「我的課」和訂貨提醒會跟著變。只有某一週不上，請到「我的課」選那位老師、按那一週的「不用訂貨」。
📅 放假日設定（國定假日、補假、校慶補假…）
設定後，這幾天的課在老師的「我的課」顯示「放假」、不算未訂貨、也不會 LINE 提醒；老師選到這天訂貨會跳出提醒。連續放假可以填一段日期。

修改密碼

廠商訂貨單

流程：① 產生「扣貨單」給學生扣庫存 → ② 學生交回後產生「訂貨單」，直接改每班的實際叫貨量，每家廠商可以先儲存（草稿）或確定叫貨 → ③ 產生「叫貨單」列印或複製文字給廠商。
字體大小：
每家廠商分成「食材合計」（重量換算成同一種單位）和「各班明細」，用「列印內容」選只印合計、只印明細，或分開兩頁都印。不含已取消、勾選「有貨」的品項，也不含器具。

自動化

管理者帳號

設成管理者的老師，用自己的帳號登入就會看到訂單彙整、廠商訂貨單、總課表、審核食材等所有管理功能（也可以修改這裡的設定），原本的訂貨功能照常可以用。也可以直接在試算表「帳號設定」的「管理者」欄打勾。

網站網址

LINE 通知、官方帳號選單、每日摘要裡的連結都會用這個網址。請貼上「部署 → 管理部署」裡正在使用的網頁應用程式網址（結尾是 /exec），存好後再按一次「設定官方帳號選單」。

LINE 官方帳號通知

到 LINE Developers 後台 → 你的 Messaging API channel → 「Messaging API」分頁最下面，按 Issue 取得 Channel access token，貼在這裡。

⟳ 更新程式

從 GitHub 讀 Claude 改好的新程式，換掉網站的程式並部署（網址不變）。每次都要輸入傳到你 LINE 的驗證碼；部署後網站打不開會自動還原。只有內建的「管理者」帳號看得到。
設定 GitHub token
GitHub →（右上頭像）Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token： Repository access 選「Only select repositories」→ 只選這個儲存庫；Permissions → Repository permissions → Contents：Read-only（其他都不要給）。產生後把 github_pat_ 開頭的 token 貼在這裡（存好後不會再顯示）。

待審核食材

核准會把食材加入食材總表並給新的食材 ID；如果其實已有這個食材，請用「對應既有食材」。兩種方式都會更新原訂單的食材資料。

新增食材到食材總表 只有管理者看得到

單位管理 管理者新增的單位不用審核，老師馬上可以用

系統學會的叫法 審核時按「對應既有食材」就會記住，下次老師打一樣的字會直接換成正式食材

只有「完全一樣」的字才會換；同一個叫法對到兩種以上食材（標 ⚠）就不自動換，讓老師自己選。學錯了按 ✕ 刪掉（存在食材總表的「別名」欄）。
